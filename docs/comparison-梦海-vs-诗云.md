# 梦海 (Oneironaut) vs 诗云 (Shiyun) — 功能差异对比

> 生成时间：2026-06-17 | 梦海版本：v0.2.0

---

## 一、3D 渲染系统

| 维度 | 诗云 Shiyun | 梦海 Oneironaut | 差距 |
|------|-----------|----------------|:--:|
| 渲染引擎 | Three.js (推测) | Three.js + React Three Fiber | — |
| 粒子总量 | ~32,657 | ~35,000 + 装饰粒子 | 🟢 梦海略多 |
| 粒子形状 | 柔光圆球 (Canvas 径向渐变纹理) | 方块 + Bloom 软化 | 🟡 诗云更柔和 |
| 粒子分布 | 噪声云团 | 3 臂对数螺线 + 3D 值噪声 | 🟢 持平 |
| 颜色梯度 | 冷蓝/青 → 暖金 双向过渡 | 4 段: 深靛蓝 → 海蓝 → 极光青 → 淡雾 → 暖金 | 🟢 持平 |
| 分层渲染 | 多前景流云层 | 4 层: 星璇云团 + 情绪色谱 + 前景流云 + 核心高亮 | 🟢 持平 |
| 点亮入场动画 | ✅ 分批渐亮 | ✅ 4 层 stagger 渐亮 (0s/1.5s/3s/3.5s) | 🟢 持平 |
| 距离感知 | ✅ 飞近时粒子变亮变大 | ✅ opacity 随相机距离衰减 | 🟢 持平 |
| Bloom 后处理 | 中高强度 | 双通道: 1.8 + 1.2 | 🟢 持平 |
| 银河旋臂 | ❌ 未观察到 | ✅ 3 臂对数螺线结构 | 🟢 梦海独有 |
| 粒子连线 | ❌ 无 | ✅ DreamConnections 神经脉冲光流 | 🟢 梦海独有 |
| Hover 高亮 | ✅ 悬停粒子高亮 | ❌ 未实现 | 🔴 缺失 |
| CanvasTexture 柔光 | ✅ 有 | ❌ R3F 序列化冲突已移除 | 🔴 缺失 |

## 七、梦海独有优势总结

1. **情绪色谱系统** — 8 种情绪径向布局，悲伤在云团边缘最大最亮
2. **神经脉冲连线** — 同情绪/同主题梦境间流光连线，像神经信号传输
3. **内容 CRUD** — 用户可写、编、删、分享梦境
4. **AI 演梦** — 内置 AI 梦境生成面板
5. **银河星璇** — 3 臂对数螺线旋臂结构
6. **落地页** — 3 段滚动渐进体验
7. **搜索 + 分享 + 时间线** — 完整的内容管理
8. **35,000 粒子光团** — 大规模可视化
